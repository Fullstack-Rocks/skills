Fictional Game & Demo Notice

Fictional Game Disclosure: Kaelvorn and Low Chord Studio are fictional creations built as a static web showcase by Fullstack Rocks. While the game is fictional, our commitment to web accessibility on this demonstration site is real and verifiable.

1. Commitment to Accessible Diegetic UI

Fullstack Rocks (writing in-universe as Low Chord Studio) is committed to ensuring that the pre-launch website for Kaelvorn (https://fullstack-rocks.github.io/skills/kaelvorn/) is accessible to all visitors, including screen-reader users, keyboard-only navigators, users with colour-vision deficiencies, and players sensitive to motion—without sacrificing the tactile look and feel of an in-game fantasy interface.

2. Conformance Status (EU Model Accessibility Statement Tier)

WCAG 2.2 Level AA is the target for this showcase. Conformance has not been established by a completed independent audit.

3. Built-In Accessibility Features of Our In-Game Interface

The interface provides keyboard controls, visible focus indicators, labelled rarity states, reduced-motion settings, text alternatives, and a region directory and skill list. These features require ongoing manual and automated verification.

4. Non-Accessible Content & Known Limitations

  • Descriptive alternatives are provided for regions, bosses, mounts, pets, character splashes, feature art, and gallery wallpapers. Gallery thumbnails that repeat an adjacent title and caption use an empty alternative to avoid duplicate announcements.

5. Preparation of This Statement & Testing Methodology

Statement prepared on 25 October 2026. Full keyboard, screen-reader, reflow, forced-colours and production-browser assessment is pending. Automated component checks alone do not establish WCAG conformance.

6. Feedback & Contact Information

If you encounter any accessibility barrier on the Kaelvorn showcase or need information in an alternative format, please open an issue or contact the maintainers via our public GitHub organisation:

  • GitHub Organisation: https://github.com/Fullstack-Rocks

7. Enforcement Procedure & European Accessibility Act Note

For information about applicable accessibility rights and reporting routes, consult your national accessibility authority.
