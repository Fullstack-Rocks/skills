# Big picture

The graph is built by programs, never by reading: lizard finds functions, SCIP indexers give exact calls, ast-grep rules find the project's own node types and connections, and the `call-depth` and `code-standards` skills supply health. Your part is to **teach** it: when a convention of this codebase isn't in the graph yet, you write it down once as an ast-grep rule, and every later build finds it for free.

Agents read the result through the `big-picture-query` skill (`bp node`, `bp neighbors`, `bp find`). Use it to check your work.

Everything in `.big-picture/` except `out/` is the team's memory of the codebase and is meant to be committed; say so when you create or change it. `out/` is regenerated by every build and ignored through `.big-picture/.gitignore`.

## Tools

Scripts are in this skill's `scripts/` folder, Python 3.11+, standard library only. They need:

- **ast-grep** and **lizard**, from the `call-depth` skill: `python3 <call-depth>/scripts/install_tools.py ast-grep lizard`
- the **SCIP indexers** for exact calls: `python3 scripts/install_tools.py` (needs Node.js; pinned, installed at user level). Without one, that language's calls are built by name and marked approx.
- the `call-depth` skill installed next to this one for health; `code-standards` too when the project has a `.code-standards/` folder.

Install what's missing yourself and tell the developer in one line what was installed.

## Build

1. Run `python3 scripts/build.py <project root>`. It prints one line: node, edge and finding counts, rule matches, the call source per language (`scip` or `approx`) and the time.
2. Read every warning above that line (a failed indexer, a skipped health source) and fix or report it.
3. Check coverage with `big-picture-query`: `bp find --type endpoint`, then `bp node` on one endpoint and one table. When a convention is missing (endpoints with no handler, a data layer with no table nodes), **teach** it.

Done when the build prints no warning you haven't reported, and every route style and data-access pattern the developer would name has nodes.

## Teach a convention

1. Find the convention in the code: a decorator, base class, call shape or naming pattern that repeats and means something (a route, a job, a table access).
2. Read [`references/node-types.md`](references/node-types.md) and write the rule: `.big-picture/types/<id>.yml` for a new kind of node, `.big-picture/edges/<id>.yml` for a connection from the code around a match to a node, `.big-picture/properties/<id>.yml` for values that belong to a node (a model's fields, which become its table's columns). Create `.big-picture/sgconfig.yml` from that reference if the project has none.
3. Write `.big-picture/rule-tests/<id>-test.yml`: at least two `invalid` cases the rule must match and two `valid` near-misses it must not.
4. Run `ast-grep test -c .big-picture/sgconfig.yml --skip-snapshot-tests` until it passes.
5. Count the convention by hand (`grep -c` on its plainest spelling) and compare with the rule's hits: `ast-grep scan -c .big-picture/sgconfig.yml --json=compact | python3 -c "import json,sys,collections; print(collections.Counter(m['ruleId'] for m in json.load(sys.stdin)))"`. A gap means the rule misses spellings or matches too much; refine it and rerun.
6. Rebuild and check the new nodes with `bp node`.

Done when the fixtures pass, the hit count matches the hand count (or the difference is explained), and `bp node` shows the new nodes connected.

## View

- **Live:** `python3 scripts/serve.py <project root>` serves the viewer at http://localhost:7478. The page rechecks the graph every 2 seconds, so a rebuild shows up without a reload, and the node pane reads source lines straight from the project. Run it in the background and give the developer the URL. To point at one node, append `#/n/<url-encoded node id>`.
- **Share:** `python3 scripts/export.py <project root>` writes `.big-picture/out/big-picture.html`: one file with the graph inside, which opens from disk. It is a snapshot: it shows no source and doesn't follow rebuilds.

The viewer ships prebuilt as `viewer/dist/index.html`. Node is needed only to change it: `npm ci && npm run build` in `viewer/`, then commit `dist/index.html`.

## Graph format

[`references/graph-schema.md`](references/graph-schema.md) defines `graph.json`. A change to a field's meaning bumps `SCHEMA_VERSION` in `scripts/graph.py`, `viewer/src/data/load.ts` and `big-picture-query`'s `scripts/graph/load.py` together.
