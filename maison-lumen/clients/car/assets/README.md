# Veyravel asset inventory

Eight new photographs generated with Nano Banana through the Gemini API CLI (`gemini-api image`) for Maison Lumen's fictional electric grand tourer. The art direction follows `../profile.md` section 7 and `../design.md`: graphite bodywork, overcast Jura daylight, pale limestone, wet tarmac, natural workshop surfaces and restrained wool, leather and satin aluminium. No photograph contains editorial text, logos, watermarks or real brand names. `../design.jpg` was viewed only as an art-direction reference; none of these files is a crop or upscale of that design.

## Production record

Each photograph was generated in a separate `gemini-api image` call at `--image-size 2K` using the closest supported aspect ratio (`21:9` for `hero-profile.webp`, `4:3` for `hero-profile-mobile.webp` and `touring-luggage.webp`, `4:5` for `fitting-portrait.webp`, and `16:9` for `materials-worktable.webp`, `assembly-controls.webp`, `founders-atelier.webp` and `jura-road.webp`), then resized with `sips` to the exact target dimensions (`sips -c 1056 3168` followed by `sips -z 960 2880` for the 3:1 desktop hero; `sips -z <height> <width>` for all others) and encoded with `cwebp -q 82`. All intermediate JPEG files were deleted. All exports match the Asset list's exact pixel dimensions and are well below 400 KB.

### Prompt set

Shared direction: one new photorealistic editorial frame per file; quiet luxury, graphite/chalk/mineral-silver/fired-clay/pale-brass palette, muted overcast Jura daylight, honest material texture, no text, lettering, labels, logos, real brands, registration plates or watermarks. Identical descriptions across prompts for the car (`the Veyravel 01, an original low two-seat electric grand tourer coupe in deep matte-metallic graphite (#171B1D) with no badges, logos or grilles, featuring a long sculpted fastback roofline, one long frameless door per side with flush handles, narrow horizontal headlamps and taillamps, and dark satin-graphite aerodynamic disc wheels`), the founders (`Iria Veyravel` and `Lucan Esmeret`), the Jura road setting, and the limestone-and-steel Saint-Claude atelier.
